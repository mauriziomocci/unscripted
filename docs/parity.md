# Parity with the legacy game

Every behaviour of the legacy game the web app and the artifact keep, change or fix, one row each, with the check that proves it. The legacy code is the oracle; a row that departs from it says so and says why. `scripts/test/parity.test.ts` (task T235, not written yet) will enforce the row count and the required rows.

| ID | Feature | Acceptance check | Target WI | Web app | Artifact | Note |
|---|---|---|---|---|---|---|
| ARCH-001 | Markdown parser age clamp | `packages/core/test/archive/markdown.test.ts`, test «brings a novel character aged 120 back aged 95» | WI-6 | Ported verbatim (`archui.js:70`) | Ported verbatim | A legacy defect, tracked for WI-6, when the legacy retires. The scope of the fix is fixed now so WI-6 does not reopen it: the parser applies the editor's own rule (3-999 when Epoca is romanzo, 3-95 otherwise) after the whole header is read, because `Età` comes before `Epoca`. Ages stored unclamped by a game are unaffected. |
| ARCH-002 | Duplicate and out-of-range inline `v` normalised on import | `packages/core/test/archive/planners/import.test.ts`, describe «which inline versions are kept» | none | Normalised before writing | Normalised before writing | The legacy keeps a file's `versions` as they are, duplicates and odd numbers included (`archui.js:249`). Here a duplicate `v` would break the insert and a `v` equal to the current version would make the next versioned save collide for ever. Only hand-made files and raw dumps carry inline versions. |
| ARCH-003 | Role synonym «infermiere» not recognised | `packages/core/test/archive/roles.test.ts`, test «does not match infermiere» | WI-6 | Ported verbatim (`archfuturo.js:25`) | Ported verbatim | The legacy pattern is `/infermer/`, which matches «infermeria» but not «infermiere» or «infermiera», so a sheet with that role keeps the text as role. Fixed together with the age clamp when the legacy retires. |
| ARCH-004 | An import with one invalid character is refused whole | `packages/core/test/archive/planners/import.test.ts`, describe «what it accepts» | none | Refused before any write (FR-046) | Refused before any write | The legacy imports every record of the file without validating it (`archui.js:249`).
