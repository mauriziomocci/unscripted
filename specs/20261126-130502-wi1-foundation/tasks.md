## Format and conventions

- **Line format**: `- [ ] **Step N**: TNNN [P?] [USn?] [HOLD?] description`, with `N` equal to the number in `TNNN`. Commits cite the `TNNN` IDs in their `CHANGE:` paragraph (for example `Tasks: T030, T031`). Steps inserted after the first numbering take the ID of the step they follow plus a letter (`**Step 92a**: T092a`); IDs are never renumbered.
- **[P]**: the step can run in parallel with the other `[P]` steps of its block once the steps it depends on are done; a GREEN step always waits for its own RED step.
- **Hold markers**:
  - `[GATED]` is a manual step that needs the owner's machine, key or explicit go; it is never run without that go.
- **Commands** (every pnpm command runs in a container, FR-002, quickstart.md): `dcr` stands for `docker compose -f docker-compose.local.yml run --rm server`; `dce` stands for `docker compose -f docker-compose.local.yml --profile e2e run --rm e2e`. Integration tests use `DATABASE_URL_TEST` pointing to a database of the session's own (isolation rule); the init script creates `unscripted_test`.
- **RED steps** end with `run:` (the command) and `expect:` (the failure). They make no commit.
- **GREEN steps** end with `commit:` (the Conventional Commit subject; the body is the project's `CHANGE:` paragraph). Commits go through the commit assistant, carry no reference to AI and no attribution line, and are never pushed by an agent. Scopes come from CLAUDE.md: `core`, `archive`, `reports`, `web`, `server`, `llm`, `artifact`, `docker`, `docs`, `ci`.
- **Docs in the same commit**: a GREEN step that changes behaviour described in `docs/architecture.md`, `docs/security.md`, `docs/alignment.md` or `docs/parity.md` updates that file in its own commit; README.md and README.it.md change together.
- **Block close** (last step of every block): the taste gate on the block's changed files (`dcr pnpm lint`, which runs ESLint with the length, depth, complexity, nested-callback, swallowed-error and floating-promise rules, `scripts/check-taste-exemptions.ts` and `jscpd`; each hit fixed or justified with `file:line`), `dcr pnpm format:check`, `dcr pnpm typecheck`, the block's tests, the 8-point review of CLAUDE.md (correctness, DRY, types, security, performance, tests, TSDoc, docs sync) as a blunt review of the block's diff by a separate review agent, fixes as their own red-then-green commits, and the Italian diary entry in `docs/diary/AAAA-MM-GG.md` (FR-104).
- **Covers:** each step ends with the requirements it serves; the coverage table at the end is built from these tags.
- **Branches**: every block commits on `20261126-130502-wi1-foundation`, the only branch (D-26-8: no held files, no local branch). Every B12 step commits there.
- **Stop rule (phase 5)**: an unforeseen case, a wrong assumption or a contradiction with plan.md or the spec stops the step and goes back to the coordinator; no step invents a design decision.
